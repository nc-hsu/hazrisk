# Examples

Worked examples on the three {doc}`example hazard curves <../data>`. Each page
is a notebook that runs when the documentation is built, so every number and
figure on it comes from the current version of hazrisk. The code needs
matplotlib (`pip install "hazrisk[plot]"`) and reads the data from the
`examples/data` folder of the repository.
